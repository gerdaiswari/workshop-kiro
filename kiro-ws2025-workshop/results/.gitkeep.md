- `app01-inventory.json` — APP01 inventory output
- `data01-inventory.json` — DATA01 inventory output
- `prerequisite-check.json` — Pre-upgrade requirement validation
- `inventory-summary.md` — Human-readable inventory report
- `baseline-APP01.json` — Pre-migration test baseline
- `baseline-DATA01.json` — Pre-migration test baseline
- `post-APP01.json` — Post-upgrade test results
- `post-DATA01.json` — Post-upgrade test results
- `comparison-report.json` — Diff comparison with PASS/FAIL
- `upgraded-amis.json` — AMI IDs from SSM Automation
